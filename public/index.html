http-server is running

A multithreaded HTTP/1.1 server written in C++17 on raw POSIX sockets.

  • GET /api/health health check
  • POST /api/jobs queue a text-analysis job (REST, JSON)
  • GET /api/jobs/{id} poll a job
  • GET /soap?wsdl SOAP service description
  • POST /soap the same jobs over SOAP 1.1
